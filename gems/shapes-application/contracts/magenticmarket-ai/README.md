# magenticmarket-ai application contract

Slot for MagenticMarket.ai (`magenticmarket.ai`), a Magentic Market
overlay. It consumes `shapes-level-8` protocol vocabulary and ships
its own contracts in the overlay repo
(`magentic-market-ai/overlays/magenticmarket-ai/contracts/`).

Empty of TTL here. ADR 0063: the substrate **names** the application;
contracts stay in the overlay.

CANONICAL: a market app **nests** under Core. It does not replace `/`
the way Shared AI Space replaces `/` with the board.

This directory names `magenticmarket-ai` and reserves it. Nothing
here is a component.
