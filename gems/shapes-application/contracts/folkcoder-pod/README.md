# folkcoder-pod application contract

Slot for a second Magentic surface. FolkCoder consumes `shapes-level-8`
protocol vocabulary and ships its own contracts here
(`FolkCoderSessionOpenEffectShape`, …). It does not import mind-pod's
routes by sharing mind-pod's operation shapes.

Empty of TTL in step 4. The directory exists so a second application can
land beside mind-pod without either being reclassified.
