# sharedai-space application contract

Slot for Shared AI Space (`sharedai.space`), a Magentic Market
overlay. It consumes `shapes-level-8` protocol vocabulary and
ships its own contracts in the overlay repo
(`shared-ai-space-app/contracts/sharedai.space/`).

Empty of TTL here, and stays that way. ADR 0063: the substrate
**names** the application; contracts stay in the overlay.

This directory names the application identifier `sharedai-space`
and reserves it. That is all it is for.

Product (stated in the overlay, not here): library of named
graphic artifacts + Fabric editor of one artifact. Catalogs 12/19
are a slot on a digest, not the drawing UI.
