# PLAN_0_159_14 — tri-state Gamer control

**Strategy:** AlphaSplash.
**Status:** draft.

## Why

The binary Game checkbox can't express the operator's full range.
Three levels:

- **STAID**       calm baseline. Per-card boxes off.
- **INTERACTIVE** current 'checked' behavior — per-card animations on.
- **GAMIFIED**    INTERACTIVE + 'go a little man crazy': light
                  gradient backdrop, display font on headings,
                  card wobble, floating persona words.

## What ships

- New `vendor/vv-web/src/gamer.js` with VvGamer class
  (▼ / LEVEL / ▲ control, localStorage persist, exports
  PERSONA_WORDS for the floating overlay).
- splash.js imports VvGamer, applies `is-gamer-<level>` class,
  flips per-card boxes, mounts/unmounts `.mm-floating-words`.
- styles.css: `.mm-gamer*` control, `.is-gamer-gamified`
  treatments (gradient bg, cursive headings, card wobble),
  `.mm-floating-word` drift keyframes.
- game-toggle.js removed.
