# Changelog

## 0.1.0 — 2026-09-16

- Initial private seam, mirrored from vv-miro.
- Plugin API browser load (`VvFigma.mount` / `applyEffect`).
- REST client for files, comments, images, webhooks.
- OAuth 2.0 authorization-code + refresh (HTTP Basic).
- Share.push onto an existing `file_key` (Figma REST cannot create files).
- Document-node Effects refuse `plugin_required` on REST.
