# PLAN_0_144_2 — urn:mm:alignment + alignment_score MCB action

Status: Active
Parent: [PLAN_0_144_0](PLAN_0_144_0.md)
Predecessor: [PLAN_0_144_1](PLAN_0_144_1.md)
Date: 2026-06-07

## Slice intent

Wrap PLAN_0_144_1's pure `Scorer` in:

1. A graph-shaped Turtle projection over the `urn:mm:alignment`
   named graph (parallel to routing / hypersource / health
   projections), and
2. A read-only `alignment_score` MCB action that returns the
   score envelope + Turtle + graph_iri.

No writes into the actual `urn:mm:alignment` graph yet — v0.1
is projection-only, matching the v0.1→v0.2 split the other
families use.

## GraphProjection

`GRAPH_IRI = "urn:mm:alignment"`. Subject is
`<urn:mm:gem:<slug>>`. Predicates:

- `a mm:GemAlignment`
- `mm:gem "<slug>"`
- `mm:propertyP1Score <float>` (three-layer)
- `mm:propertyP2Score <float>` (jsonld-wire)
- `mm:propertyP3Score <float>` (shacl-shapes)
- `mm:propertyP4Score <float>` (small-surface)
- `mm:propertyP5Score <float>` (graph-projection)
- `mm:propertyP6Score <float>` (pattern-exec)
- `mm:propertyP7Score <float>` (loss-axis)
- `mm:compositeScore <float>`
- `mm:lAlignment <float>`
- `mm:checkedAt "<iso8601>"`
- `mm:actionCount <int>`

## MCB action

```
alignment_score(gem: "vv-graph", actions: ["engine/.../sparql_query.rb", …])
  → {
      ok:              true,
      gem:             "vv-graph",
      p1: …, p2: …, p3: …, p4: …, p5: …, p6: …, p7: …,
      composite_score: 0.64,
      l_alignment:     0.36,
      checked_at:      "...",
      turtle:          "@prefix mm: … .\n<urn:mm:gem:vv-graph> a mm:GemAlignment ; …",
      graph_iri:       "urn:mm:alignment"
    }
```

Refusals:
- `:gem_required` — blank gem slug.

Read-only; annotated `read_only: true, destructive: false`;
gated `actor: :none`; registered next to `health`.
