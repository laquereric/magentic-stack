# Runbooks

Operational procedures for the governed pod. Each runbook is a numbered,
step-by-step checklist with an explicit rollback path.

Planned runbooks:
- Deploy the 5-container MIND Pod (boundary defaults on).
- Advance an upstream pin (NOOA / Switchyard) with SBOM + provenance + rollback.
- Export governance evidence for a pilot.
- Incident response: suspected boundary bypass.
