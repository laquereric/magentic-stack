helper between `gems/rails-cpcp/front` and `runtimes/mind-pod` is a new
import edge those trees do not otherwise have, and costs more than it
saves for five sites. Two tiny helpers would still be a second pattern.
The pattern to copy already exists in this tree, twice. Do not invent
one.

`HTTPError` is caught. `URLError` is not. A connection failure and a
refusal are not the same event.
