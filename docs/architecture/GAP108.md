Measurement. No port. No new credential path. Asymmetry not relaxed.

(251 Node lines). Row 5 then built `ROLE=config` with put+list only,
`ALLOWED.fetch` refusing `vault.secret.get` before any network call.

## Two stores, not one

Discovery reads **switch** state (`sources.mjs` `STATE_DIR` default
`/state` → compose bind `../../.agent/secrets`), not vault
(`/vault/secrets.json`). Even if `ROLE=config` were allowed
`vault.secret.get` (it must not), today's discovery would still be
reading a different file.

`llm-plane` is the vault allowlist identity that may `get`. Switch
holds `state.keys` for its own dispatcher. Those are not yet the same
store.
