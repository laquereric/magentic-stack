# Gaps 39/43: the closed path set is declared and gated

Built at SHA of this change. Row 39 (the path parameter must be a CLOSED
set) and row 43 (two writers on one file becomes a runtime operation) close
together: the set is `tooling/compose/store_bindings.json`, the gate is
`tooling/compose/check_store_bindings.py`.

## 1. The set (row 39)

Three sqlite paths, each with its volume, env var, and declared binders:

| Store | Path | Volume | Env | rw | ro |
|---|---|---|---|---|---|
| domain | `/data/mind_pod.sqlite3` | `mind-data` | `DB_PATH` | back, backjob | bus |
| bus | `/bus-data/bus.sqlite3` | `bus-data` | `BUS_DB_PATH` | bus | — |
| mind | `/mind-data/nooa.sqlite3` | `mind-nooa-data` | `DB_PATH` | mind | — |

Population: **8** `DB_PATH:` + **2** `BUS_DB_PATH:` lines across the two
compose files; **4** named volumes. The journal is not a fourth path
(0052/73; ROW8 §2). Host-relative `database.yml` defaults are not members.

## 2. The gate (row 43)

Per compose file the checker proves: every `DB_PATH`/`BUS_DB_PATH` value is
an exact closed-set member for that var; every sqlite volume mount matches
the declared writer-set **and mode** (`:ro` mounts must be declared ro, rw
mounts declared rw); every declared (store, role) pair appears with
mount+env; the three named volumes exist; no other `.sqlite3` literal
appears; every named role exists in `domain_writers.json` (+`mind`, a
service name, not a Rails ROLE). 50 examined, 0 skipped.

Plants (`plant_store_bindings.py`): rogue path, back binding bus-data,
dropped bus volume — plus clean and empty-root. All fail as required.

## 3. What this does not settle

**0051 §5** ("no two roles at one path") is still false of the domain file:
back+backjob share it by 0056 declaration. The gate enforces ROW8's
writer-set reframing, not the sentence — withdrawing it is an amendment,
still the owner's (ROW8 §7). `unenforced_because` on 0051 was updated to
say the set is declared and gated; the effect itself stays unbuilt and
persist (row 8) still does not exist to serve it.
