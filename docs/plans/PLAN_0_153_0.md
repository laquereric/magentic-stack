# PLAN_0_153_0 — Doctrine graph + fs_X envelope context

The still-relevant style/convention content from the legacy
`~/Documents/Focus/agent-os/rules/*.md` (Ruby + JavaScript) is
lifted into the substrate as doctrine triples in a new named
graph `urn:mm:doctrine`. Every `fs_read` / `fs_write` /
`fs_edit` MCB call attaches `envelope[:doctrine]` with the
entries whose `appliesToGlob` matches the touched path — so
mm-cli (and the LLM behind it) gets realtime convention
guidance keyed by file type, without having to remember it.

This closes the `feedback-mcb-context-from-graph` doctrine:
context flows from the graph, not from filesystem rule files.

## Shape

### Storage

  named graph: urn:mm:doctrine
  vocab:
    urn:mm:vocab/Doctrine          rdf:type
    urn:mm:vocab/doctrineId        string id (e.g. 'ruby-1', 'javascript-1')
    urn:mm:vocab/appliesToGlob     File.fnmatch glob ('*.rb', '*.js')
    urn:mm:vocab/body              rule body (markdown)
    urn:mm:vocab/sourceFile        provenance (e.g. 'docs/architecture/...' or the legacy path)
    urn:mm:vocab/severity          'advisory' | 'rule'

### Code

  Harness::Doctrine                 namespace + facade (for_path)
  Harness::Doctrine::Catalog        in-code authoritative list (.entries)
  Harness::Doctrine::Persister      .seed! (idempotent via DELETE WHERE; never_raise envelope)
  Harness::Doctrine::Lookup         .for_path(rel) → [{ id, body, applies_to_glob, severity }]

Lookup memoizes a seed-once gate so the graph self-heals on
first call; explicit re-seed available via Persister.seed!.

### fs_X envelope additions

  envelope[:doctrine] = [
    { id: 'ruby-1', applies_to_glob: '*.rb', severity: 'rule',
      body: '...' },
    ...
  ]

Added to: fs_read (success), fs_write (success), fs_edit (success).
Never returned on failure envelopes — doctrine is guidance not
refusal.

## Acceptance

1. After substrate boot, sparql_query against urn:mm:doctrine
   returns ≥2 Doctrine subjects (ruby + javascript).
2. fs_read of a *.rb path returns envelope[:doctrine] with the
   ruby entry.
3. fs_read of a *.js path returns the javascript entry.
4. fs_read of a *.png path returns envelope[:doctrine] == [].
5. fs_write success envelope carries the same field.
6. Re-running Persister.seed! is idempotent (no triple drift).
7. Lookup spec passes.
