# Row 115 — withdrawn ADR text is marked at origin

Measured 2026-09-03 from `73d5509`. **Built.** Owner decision
2026-09-03: any sentence quoted in an amendment's Withdrawn list must
be struck at its source line with a pointer to the amendment, and a
checker must require it.

`enforced_by` gates whether a decision is ENFORCED. This row gates
whether its stated text is still TRUE.

---

## What was wrong

0050 amendment 2 quoted seven withdrawn sentences and left the
originals live at `:38` ("Rails Event Store, with a CPCP interface")
and `:131` ("BUS implements RES"), ~160 lines above the list. A
top-down reader takes them as current. 0046 and 0047 append amendments
with no Withdrawn list at all — same hazard, no quotes to match.

## What the gate requires

`tooling/cpcp/check_withdrawn_quotes.py`:

- Every ADR with an `Amendment` heading is examined (the sweep).
- Quoted sentences in a `**Withdrawn...:**` list must appear **outside
  that list**, inside `~~...~~`, with `withdrawn` in the following
  pointer.
- A quote that exists only in the list is **unmatched: FAIL**, not a
  silent pass.
- An amendment with no Withdrawn list is examined (0 quotes) — not
  skipped. Adding a Withdrawn list later is what brings it under the
  quote rule. 0050 is first because it is the one that already quotes.

Origin marks on 0050 use `~~text~~ *(withdrawn, amendment 2)*`.
The Withdrawn bullets were aligned to verbatim origin strings so the
checker can match them. That is the same retraction; it is not a new
decision.
