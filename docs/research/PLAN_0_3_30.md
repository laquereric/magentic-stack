# PLAN 0.3.30 — Implement View Pipeline Tables

Implement the 5 new tables from PLAN_0_3_29: Design, DesignConcern, DesignEval, Actor, Intention. Create migrations, AR models, and seed one Design with concerns for the "Explore AI Then Cancel" scenario.

## Steps

1. Migration: create designs, design_concerns, design_evals, actors, intentions
2. AR models with validations and relationships
3. Seed: one Design ("MagenticMarket Home Page") with concerns + one Actor + Intentions for Scenario 1
4. Verify: `rails db:migrate`, `rails db:seed`, `rails runner` to confirm relationships

## Migration

```ruby
create_table :designs — slug, title, description, version
create_table :design_concerns — design_id FK, name, description, priority, criteria
create_table :design_evals — design_concern_id FK, evaluator, result, score, notes, evaluated_at
create_table :actors — name, actor_type, session_id, metadata
create_table :intentions — actor_id FK, action, target, payload, context_id FK, status
```

## Seed Data

Design: "MagenticMarket Home Page"
  Concerns:
  - "header-domain": Header displays the current domain
  - "main-content": Main region shows welcome + featured content
  - "ai-modal": AI modal opens with assistance options
  - "sidebar-collapse": Right sidebar collapses when not in use
  - "modal-dismiss": Modal can be dismissed, returning to base state

Actor: "Visitor" (human)
  Intentions for Scenario 1 (Explore AI Then Cancel):
  - click AI button → creates modal Context
  - cancel modal → deletes modal Context
