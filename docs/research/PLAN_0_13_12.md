# PLAN 0.13.12 — Materialized Model: Pre-Computed Views for Products

## The Problem

Product data is re-derived on every request:

| Consumer | What it computes | Queries |
|---|---|---|
| `render_product_card` | specs lookup + TCO calculation | 6 spec queries + TCO per product (fixed by A in 0.13.11, but still computed per request) |
| `MCP schema_product` | Schema.org shape + affiliate URL + Product lookup per item | 1 Product.find_by per item |
| `MCP schema_product_full` | Full product + all specs | Product + specs query |
| `WikiCompiler.hydrate` | Triples + specs + price parsing | Triple queries + Product lookup + spec iteration |
| `ChatResponseTemplate` | Product items + affiliate URL + buy_url | Product.find_by per item |

The same product is reshaped into different formats by different consumers — but the underlying data (specs, TCO, affiliate URL, Schema.org shape) changes only when the product feed updates. This is re-derivation — the exact problem the Knowledge Research document identifies as RAG's second failure mode.

## The Materialized Model

A `Materialized` record stores pre-computed views of a source record. One source (Product) can have multiple materialized views (card, schema, wiki, mcp).

```
Product (source)
  └─ Materialized records:
       { kind: "card",   data: { cpp, ink, duty, tco_total, affiliate_url, ... } }
       { kind: "schema", data: { @type: "Product", name, brand, offers, url, ... } }
       { kind: "wiki",   data: { name, brand, price, availability, specs, ... } }
```

Each `kind` is a pre-computed view optimized for a specific consumer. When the product feed updates (`ProductTripler.index_all!` or `feed:refresh`), all materialized views are rebuilt.

### Migration

```ruby
create_table :materializeds do |t|
  t.string :source_type, null: false   # "Product"
  t.integer :source_id, null: false
  t.string :kind, null: false          # "card", "schema", "wiki"
  t.json :data, default: {}
  t.datetime :computed_at
  t.timestamps
end
add_index :materializeds, [:source_type, :source_id, :kind], unique: true, name: "idx_materialized_source_kind"
add_index :materializeds, :kind
```

### Model

```ruby
class Materialized < ApplicationRecord
  belongs_to :source, polymorphic: true

  scope :for_kind, ->(kind) { where(kind: kind) }
  scope :cards, -> { where(kind: "card") }
  scope :schemas, -> { where(kind: "schema") }

  def stale?
    computed_at.nil? || source.updated_at > computed_at
  end
end
```

### Product Association

```ruby
class Product < ApplicationRecord
  has_many :materializeds, as: :source, dependent: :destroy

  def materialized(kind)
    materializeds.find_by(kind: kind)&.data
  end

  def card_data
    materialized("card")
  end

  def schema_data
    materialized("schema")
  end
end
```

## Builders

Each kind has a builder that computes the materialized data from the source.

### Card Builder

```ruby
class Materialized::CardBuilder
  def self.build(product)
    specs = product.product_specs.each_with_object({}) { |s, h| h[s.name] = s.value }
    tco = TcoCalculator.calculate(product, years: 3, pages_per_month: 500)
    {
      "name" => product.name,
      "brand" => product.brand,
      "sku" => product.sku,
      "price" => product.price,
      "category" => product.category,
      "rating" => product.rating,
      "cpp" => specs["cost_per_page_mono"],
      "ink" => specs["ink_system"],
      "duty" => specs["duty_cycle_monthly"],
      "tco_total" => tco[:total_cost],
      "affiliate_url" => AffiliateLink.for_product(product)
    }
  end
end
```

### Schema Builder (Schema.org/Product for MCP)

```ruby
class Materialized::SchemaBuilder
  def self.build(product)
    {
      "@context" => "https://schema.org",
      "@type" => "Product",
      "name" => product.name,
      "sku" => product.sku,
      "gtin" => product.gtin,
      "url" => AffiliateLink.for_product(product),
      "brand" => { "@type" => "Brand", "name" => product.brand },
      "category" => product.category,
      "image" => product.image_url,
      "description" => product.description,
      "offers" => {
        "@type" => "Offer",
        "priceCurrency" => "USD",
        "price" => product.price,
        "availability" => product.in_stock ? "https://schema.org/InStock" : "https://schema.org/OutOfStock"
      },
      "additionalProperty" => product.product_specs.map { |s|
        { "@type" => "PropertyValue", "name" => s.name, "value" => s.value }
      }
    }.compact
  end
end
```

### Wiki Builder (for WikiCompiler prompts)

```ruby
class Materialized::WikiBuilder
  def self.build(product)
    offers_triple = Triple.about(ProductTripler.product_uri(product))
                          .find { |t| t.predicate == "schema:offers" }
    offers = offers_triple ? (JSON.parse(offers_triple.object) rescue {}) : {}
    specs = product.product_specs.each_with_object({}) { |s, h| h[s.name] = s.value }
    {
      "name" => product.name,
      "brand" => product.brand,
      "price" => offers["price"] || product.price,
      "availability" => offers["availability"] || "InStock",
      "specs" => specs
    }
  end
end
```

## Rebuild Pipeline

```ruby
class Materialized
  BUILDERS = {
    "card" => Materialized::CardBuilder,
    "schema" => Materialized::SchemaBuilder,
    "wiki" => Materialized::WikiBuilder
  }.freeze

  def self.rebuild_all!(source)
    BUILDERS.each do |kind, builder|
      record = find_or_initialize_by(source: source, kind: kind)
      record.data = builder.build(source)
      record.computed_at = Time.current
      record.save!
    end
  end

  def self.rebuild_kind!(kind)
    builder = BUILDERS[kind]
    Product.includes(:product_specs).find_each do |product|
      record = find_or_initialize_by(source: product, kind: kind)
      record.data = builder.build(product)
      record.computed_at = Time.current
      record.save!
    end
  end
end
```

### Integration with feed:refresh

```ruby
# In feed:refresh rake task and MCP update_product_feed
ProductTripler.index_all!
Product.includes(:product_specs).find_each { |p| Materialized.rebuild_all!(p) }
WikiCompiler.compile_all
```

## Consumers Switch to Materialized

### render_product_card

```ruby
def render_product_card(product, tco: nil)
  card = product.card_data
  if card
    cpp = card["cpp"]
    ink = card["ink"]
    duty = card["duty"]
    tco_total = card["tco_total"]
    affiliate_url = card["affiliate_url"]
    # Zero queries, zero computation
  else
    # Fallback to live computation (first load before materialization)
    tco ||= TcoCalculator.calculate(product, years: 3, pages_per_month: 500)
    cpp = product.spec("cost_per_page_mono")
    # ...
  end
end
```

### MCP schema_product_full

```ruby
def schema_product_full(product, specs)
  product.schema_data || Materialized::SchemaBuilder.build(product)
end
```

### WikiCompiler.hydrate

```ruby
def self.hydrate(uri)
  sku = uri.delete_prefix("urn:mm:product:")
  product = Product.find_by(sku: sku)
  return nil unless product
  wiki = product.materialized("wiki")
  return wiki if wiki
  # ... live computation fallback
end
```
