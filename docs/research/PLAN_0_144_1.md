# PLAN_0_144_1 — Harness::Alignment::Scorer

Status: Active
Parent: [PLAN_0_144_0](PLAN_0_144_0.md)
Date: 2026-06-07

## Slice intent

First slice of the alignment family. A pure stateless
`Harness::Alignment::Scorer.score(gem:, actions:, paths:)` that
runs the seven per-property heuristics from
[`../architecture/principles/biological-interface-gem.md`](../architecture/principles/biological-interface-gem.md)
and returns a structured score envelope.

No MCB action yet (144_2 wraps), no graph projection (144_2), no
L axis (144_4). This slice is the pure function the rest of the
family composes over.

## API

```ruby
Harness::Alignment::Scorer.score(
  gem:      "vv-graph",       # gem slug; required
  actions:  ["engine/vv-graph/app/services/.../sparql_query.rb", …],  # action source paths; optional, defaults to []
  paths:    { library: ..., engine: ..., presentation: ... }      # optional override of the conventional layout
)
# → {
#     gem: "vv-graph",
#     p1: { score: 1.0, present: { library: true, engine: true, presentation: true } },
#     p2: { score: 0.5, matched: 1, total: 2 },
#     p3: { score: 0.0, matched: 0, total: 2, missing: ["sparql_query", "sparql_update"] },
#     p4: { score: 1.0, action_count: 2, limit: 7 },
#     p5: { score: 1.0, evidence: "library/vv-graph/sparql.rb" },
#     p6: { score: 0.0, expected: "bin/vv-graph-pattern" },
#     p7: { score: 1.0, evidence: ["library/vv-graph/loss/lint_offenses.rb"] },
#     composite_score: 0.643,
#     l_alignment:     0.357
#   }
```

## Heuristics (v0.1)

Matches the direction's per-property heuristic table:

- **P1 three-layer:** fraction of `{library, engine, presentation}/<gem>/`
  directories present on disk.
- **P2 JSON-LD wire:** fraction of `actions` whose source
  contains `@context` / `:at_context` / `@graph` / `:at_graph`
  references. Empty `actions:` returns score 1.0 with
  `note: :no_actions`.
- **P3 SHACL shapes:** fraction of `actions` for which both
  `<library>/shapes/<action>.input.ttl` and
  `<action>.output.ttl` files exist. Empty `actions:` returns
  score 1.0 with `note: :no_actions`.
- **P4 ≤7 actions:** `1.0` if `actions.size <= 7`, else
  `7.0 / actions.size`. The Direction documents this as a
  soft target with a sharp upper bound.
- **P5 graph projection:** `1.0` if `library/<gem>/graph_projection.rb`
  exists OR any action references `Vv::Graph::Sparql.execute`
  / `.update` OR any action references `urn:mm:<short-slug>`
  literal IRI. Else `0.0`.
- **P6 pattern exec:** `1.0` if `bin/<gem>-pattern` exists,
  else `0.0`.
- **P7 L axis:** `1.0` if `library/<gem>/loss/*.rb` exists OR
  `library/<gem>/.no-loss-axis` opt-out marker exists, else `0.0`.

## Composition

Per the doctrine:

```
composite_score = mean over P1..P7 of score_P_i(G)
l_alignment     = 1.0 - composite_score                  ∈ [0, 1]
```

Zero `l_alignment` is perfect alignment.

  per the doctrine, separate from the scorer.

  call each action with a probe input + check `@context`
  in the response.

## What this unblocks

  urn:mm:alignment Turtle projection.
- 144_3: gem inventory feeding the Scorer with the corpus to
  iterate.

  Scorer at Turn open + close; the delta drives L.
