# grammar/cpcp/  🟢 OWN IT

**CPCP — the Cyborg-Pod-Contract-Package.** The contract profile served at the
`/_cpcp` seam: resources projected as CID-grounded JSON-RPC-LD, conforming to the
broader JSON-RPC-LD protocol.

- Implemented by [`../../interfaces/rails-cpcp/`](../../interfaces/rails-cpcp/).
- Deploy doctrine: CPCP is **mandatory two-pod** (a Rails BACK plus a distinct
  FRONT), never co-located. See `runtimes/`.
- SHACL shapes define the conforming Cyborg Channel profile.
